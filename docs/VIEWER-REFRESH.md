# 查看器界面与交互更新

更新日期：2026-10-17。适用于开源版标准查看器；同步后，新生成的项目和任务板示例使用相同界面。

## 界面

品牌中文名为“AI原型生成器”。Logo 以单一白色折带组成 P，中央的三角留白表达从需求到可运行原型；使用 OpenAI 官方 imagegen 探索后整理为纯 SVG，并提供透明 PNG 与白色单色版本。主色为 `#2537B8`，配合浅灰工作面与白色面板。原图与生成提示词见 [Logo 资产说明](../assets/branding/README.md)。

左侧页面树支持搜索与切页；中部画布默认适应可用空间；右侧只保留“标注 / 页面说明”，默认标注，独立滚动且文字不随画布缩放。页面说明用一句话定位当前页，背景、异常与业务规则、验收清单按需展开，文档为紧凑链接；有待确认事项时显示计数并置顶，无事项不占位，已处理事项可追溯。100% 对应页面声明的原始视口像素。支持七档缩放、恢复适应、侧栏收起、当前页链接复制和快捷键。

顶栏保持单行：页面/流程、缩放和面板开关集中排列，复制链接直接显示在顶部；小于 1000px 时“更多操作”仅保留缩放，桌面不显示空菜单。删除全局状态切换、额外翻页、左右方向键翻页与重置视图功能。移除重复项目名称、页面标题、侧栏计数、说明标题和口号，快捷键入口移至右下角。目录分组和页面统一字号，以字重、图标、缩进与层级线区分。

默认演示主要业务流程，状态适用性、规则与业务流转集中在右侧“页面说明”的“异常与业务规则”。需要展示某种状态效果时，按需增加独立状态页，纳入页面地图与逐页确认；查看器不向业务页面强制发送“正常态”指令，不覆盖独立状态页的默认画面。

查看器与业务原型的原生单选下拉框共用 `select-controls.css`，统一箭头、文字留白与 RTL/强制颜色降级。同步器会复制该文件，通用业务页面在自身样式后引入；已有独立组件遵循项目规范。生成约束见 [设计系统参考](../references/design-system.md)。

运行预览继续使用项目实际页面和参数；移动端设备按窗口宽高适应，iframe 保留声明视口。窄屏说明和页面目录改为抽屉，支持关闭、Esc、焦点返回与 Tab 范围约束。

标注点击联动画布点位，同一条可反复展开/收起，支持全部收起和 Enter／空格键操作；画布编号始终打开对应说明。支持新增、编辑、删除、恢复系统说明和重定位，操作按钮不触发折叠。未保存的编辑切页时提醒；正常保存不在底栏和标注列表重复提示，也不保留空白占位。无写入接口时显示“仅浏览器保存”，接口失败时保留本机缓存并明确提示。

两个面板的同级分割线和标题行采用相同基准，展开条目不再通过负边距外扩。正文标准分段按标签与规则分层，嵌套记录以缩进和细竖线区分；长标题自然换行，开合不改变标题区域高度。阅读样式不会改写标注原文。

## 本地验证

核心检查无需安装 npm 运行依赖：

```bash
npm run check
```

可选浏览器集成测试需要 Playwright，仅用于开发验收：

```bash
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
npm run test:browser
```

已有 Chrome 的环境也可使用 `PLAYWRIGHT_BROWSER_CHANNEL=chrome npm run test:browser`。CI 独立运行 Chromium 验收并保留截图；本地截图输出到忽略目录 `test-results/viewer/`。

浏览器覆盖：画布适应与真实缩放、搜索与键盘操作、右侧状态说明、筛选自然空态、独立状态页保持自身画面、任务完成与返回筛选恢复、标注切页保护与文件持久化、新增/重定位/删除/恢复、保存失败后缓存恢复、关联 Markdown、标注点位联动、流程总览、导航消息来源校验、375–1440px 布局、移动端实际视口和纯静态部署缓存。

查看器改版初次本地验收包含 19 项核心与独立包测试、18 组浏览器检查。2026-10-17 标注与说明面板升级后的本地验收为 34 项核心/标注/独立包检查、23 组浏览器检查，任务板产物校验为 0 错误、0 警告；公开包文本扫描通过。新增检查覆盖默认标注、两页签、折叠规则与验收清单、待确认计数及窄屏提醒、v2.2 可选背景与旧版严格校验、开合边线与行高稳定、长标题及备注原文安全显示。GitHub CI 只对应其触发提交，本地新增检查通过不代表远端已执行。

模块标注默认使用 v2.2：不强制凑三段，按模块归属、有效正文与适用规则交付；读取成功时以 page-spec 为系统说明基线，镜像仅作降级。重跑保留未提供维度，明确删除才移除，并同步镜像、保护人工覆盖层。规则与用法见 [模块标注规则](../references/annotation-authoring-rules.md)。
