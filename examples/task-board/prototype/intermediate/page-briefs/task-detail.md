# 任务详情定义

## 1. 页面定位与目标
帮助团队成员阅读任务说明并标记完成。这是虚构公开样例，仅用于说明工作流。

## 2. 用户与使用场景
使用者为团队成员。从任务列表进入，查看并更新任务进度。

## 3. 页面功能结构与信息架构
任务详情包括标题、说明、成员代号、日期和状态；操作区支持完成与返回。

## 4. 内容与数据规则
读取当前浏览器会话中的虚构任务。无会话数据时加载三条固定任务。空关键词表示全部；进度筛选与关键词同时生效。完成后会话保存并更新列表。

## 5. 关键交互与路由
任务链接进入详情并传递任务 ID；返回列表恢复关键词和筛选条件。标记完成不会重复创建记录。

## 6. 页面状态与降级
正常态展示内容；加载态提示正在加载；空态提示没有任务或找不到任务；失败态可重试。不包含权限与过期业务。

## 7. 原型制作说明
独立 HTML 入口，Web 视口 1280 × 800；窄屏按单列适配。使用本地 CSS、系统字体及通用 Logo，无远程资源。

## 8. 待确认项
样例无未决项；真实项目的权限、数据服务、协作冲突与业务口径需重新确认。
