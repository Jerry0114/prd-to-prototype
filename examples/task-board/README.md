# 团队任务板

从零编写的虚构案例，包含任务列表和详情、搜索筛选、完成任务、状态切换、模块标注与文档预览。

所有任务、成员代号和确认记录都是测试夹具。`confirmedBy: "user"` 仅演示校验格式，不代表真实用户授权。不要将样例的确认记录复制到实际项目。

在仓库根目录运行 `npm run demo`，打开 http://127.0.0.1:8766 。运行 `npm run validate:demo` 验证来源哈希与模型。

来源文档在 [prototype/docs/PRD.md](prototype/docs/PRD.md)。生成数据只保存在当前浏览器会话；查看器人工标注保存在项目内，默认被 Git 忽略。
